# Sounds

Each folder is one sound set. Files are only renamed (and PyChess's converted
from Ogg to MP3); the sounds themselves are unchanged.

Folder | Source | Author | License
--- | --- | --- | ---
sfx, piano, nes, futuristic | Lichess, https://github.com/lichess-org/lila public/sound/<set> | Enigmahack | GNU AGPL v3 or later
lisp | Lichess, https://github.com/lichess-org/lila public/sound/lisp | EdinburghCollective | CC BY-NC-SA 4.0 (non-commercial)
pychess | PyChess, https://github.com/pychess/pychess sounds/ | PyChess authors | GNU GPL v3

Lichess file names map as Move -> move, Capture -> capture, Check -> check,
Castles -> castle, GenericNotify -> success, Error -> wrong. PyChess's map as
move1 -> move, capture1 -> capture, castle -> castle, check1 -> check,
invalid -> wrong, success -> success. See lila's COPYING.md and PyChess's
LICENSE and ARTISTS files.

Lichess's "standard" set and chess.com's sounds are not freely licensed and are
not included.
